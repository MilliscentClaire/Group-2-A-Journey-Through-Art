# Group 2 Art Portfolio & Interactive Exhibition — Asset Placeholder

Place your team's images and exported portfolio PDF here:

1. **Images Directory**: `public/images/`
   - Store local artwork images or Google Drive downloads here (e.g., `Part1_Slide4.jpg`, `Part3_Slide19_2.jpg`).
   - The app prioritizes local images first, then falls back to public-domain Wikimedia Commons images, and lastly displays a fine-arts museum placeholder card.

2. **Static PDF File**: `public/Group2_Art_Appreciation_Portfolio.pdf`
   - When generated from Mode 3 ("Export All Pages" -> "Export All 36 Pages to PDF" in landscape), save it here.
   - Mode 2 ("PDF Archive") will automatically embed and serve it.
